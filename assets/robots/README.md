# Robot silhouette references

Filled contours traced from the images or rendered from the 3D models linked below. SVG backgrounds are transparent. Each robot has a monochrome SVG, a teal-to-lavender gradient SVG, and a 512px transparent PNG.

`robot-skyline-data.js` holds the articulated, to-scale versions used in the page footer. Sizes come from the 3D models for Go2, A2-W, ANYmal C, KUKA, UR10e and [Spot](https://github.com/bdaiinstitute/spot_description) (MIT), from the 330 mm wheel diameter for Husky, and from a reported 1.42 m height for HoLLiE. The forklift, the arm tools and the A2-W wheel size are illustrative.
